## In my own words
- Metadata: collected when sample is being brought or taken. it gives information on when the sample was taken also when the variant was first seen. 
- Raw data: a data outputted after sequencing. contains data that has not been removed, changed 
- Processed data: anything the computer produces from the raw data, for example data that has been cleaned , data that has been compared to a reference genome
- Quality: quality score gives an idea of which letter in a read is of high quality and which letter in a read is of low quality
- Reads: refer to sequence of letters after sequencing

## Why the raw data should never be edited
- you can go back to it if you make a mistake

## New words I learned
- Read: a short piece of sequence produced by the sequencer
- Quality score: how sure the machine is that one letter was read correctly
- FASTQ: the file format that holds raw reads with quality scores
- Raw data: the file exactly as it came off the machine
- Processed data: what the computer produces from the raw data

## What I learned
- i learnt the processes involved from sample collection to the computer
- i learnt the difference between raw data and processed data
- i learnt that its important to check the quality score of letters in a read
