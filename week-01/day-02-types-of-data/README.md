## Goal
Name the main biological data types and identify which one sits behind real figures from a paper.

## The five data types in my own words
- Sequence: the letters in the genome of an organism, and how they are arranged.
- Variant: a difference in a sequence compared with a reference. For example, C to T at position 5.
- Structure: the 3D shape of a molecule. Drug designers use it to find or design molecules that fit the protein.
- Expression: how active a gene is. It shows which genes are switched on, for example in a parasite inside red blood cells.
- Metadata: information about the sample, such as country and collection date. It helps place a variant in time and space.

## Why a reference is needed
A reference genome is a shared starting point, like the capital city used to measure distances. It is not the "correct" sequence. Variants are always described as differences from it, so labs can compare results with the same coordinates.

## New words I learned
- Polymorphism: a variant that is seen in a population
- MDR (multidrug-resistant): TB resistant to at least isoniazid and rifampicin
- XDR (extensively drug-resistant): MDR plus resistance to further drugs
- Reference genome: a standard sequence used as a shared yardstick (for TB, H37Rv)
- Caption: the text under a figure that explains what it shows
