## Goal
Say what databases, analysis software and programming languages are for, and find one gene in three databases.

## The three kinds of tool in my own words
- Database: refers to a collection of data that can be accessed and downloaded
- Analysis software: refers to a computer tool that takes data in, works on it, and brings an output
- Programming language: refers to a set of instructions given to the computer

## New words I learned
- Database: an organised collection of data you can search and download
- Analysis software: a tool that does one fixed job on data
- Programming language: a way of giving the computer your own instructions
- Reviewed entry: a UniProt entry checked by a curator
- Domain: a part of a protein with a specific job

## What I learned
- I learnt to different databases available and what each contain
- I also learnt you should know the goal of a particular research that would guide you in the right database to select, the right analysis software and the right programming language
